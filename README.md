# Ticket Bari

Ticket Bari is a modern ticket booking and management platform built with Next.js. It provides a smooth experience for users to browse tickets, book them online, and track their bookings, while admins and vendors can manage listings, approvals, users, and revenue from dedicated dashboards.

## Features

- User-friendly ticket browsing and booking experience
- Role-based access for users, vendors, and admins
- Vendor dashboard to add, edit, and manage tickets
- Admin dashboard to approve tickets and manage users
- Secure checkout integration with Stripe

## Packages and Dependencies

This project uses the following main technologies and libraries:

- Next.js for the frontend and app routing
- React for building interactive user interfaces
- Tailwind CSS for styling
- Stripe for secure payments and checkout
- Better Auth for authentication
- MongoDB for database storage
- Recharts for dashboard charts
- Framer Motion and Swiper for animations and sliders

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open http://localhost:3000 in your browser
